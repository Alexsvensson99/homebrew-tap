# Homebrew Tap for PkgLift

Install the latest signed and notarized Apple Silicon release of PkgLift:

```bash
brew install Alexsvensson99/tap/pkglift
```

PkgLift supports Apple Silicon Macs running macOS 14 Sonoma or later. Source
code and release notes are available in the
[PkgLift repository](https://github.com/Alexsvensson99/PkgLift).
